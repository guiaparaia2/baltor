Privacy Policy

Last updated: November 21, 2026

1. Scope

This policy covers the "BALTOR Publisher", an internal desktop tool the BALTOR team uses to publish its own gameplay clips to the official BALTOR TikTok account.

2. Data we access

When the team connects its TikTok account, TikTok returns an access token, a refresh token, the account's open ID, the authorized scopes, and basic profile information (display name, username and avatar). We also read the creator settings TikTok provides for posting (allowed privacy options, maximum video length, comment/duet/stitch settings).

3. How we use it

Only to show which account is connected and to upload or publish the team's own videos with the captions the team writes.

4. Storage

Tokens are stored only on the team's own computer, in a local file that is never uploaded or shared. No server or database is used.

5. Sharing

We do not sell or share any data with third parties. We do not collect data from other TikTok users.

6. Deleting data

Access can be revoked at any time in the TikTok app (Settings and privacy > Security > Manage app permissions). Deleting the local file removes all stored tokens.
